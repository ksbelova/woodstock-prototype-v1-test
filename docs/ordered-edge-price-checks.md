## Реализовано

- Отдельные orderedEdgeCatalog и orderedEdgeUnavailable. Исходные edgeCatalog (25 складских позиций), edgeRates и порог операции 40 м не изменены.
- 253 наименования, 2233 оценённых сочетания типа и толщины, 44 явных отсутствия цены. «Х» не является нулём или запретом производства.
- Розничные, клиентские и объёмные цены прочитаны из соответствующих листов. Колонка сростки по длине L не является ценой материала кромки и не импортирована в материал.
- 202 материала связаны со шпоном по точному наименованию. Для остальных автоматическое соответствие не придумано; сам материал можно выбрать по точному названию прайса.
- Сначала подходящая складская цена. Заказная используется для отсутствующей складской позиции/ширины при однозначном совпадении материала. Двойного начисления нет.
- Материал: метраж × ширина / 1000 × ₽/м². Запас 20% только при кромлении деталей, без запаса для отдельного рулона. Работа по кромлению считается отдельно.
- Применение минимума закупки кромки к готовым деталям не добавлено. Действующая проверка 50 м отдельного рулона и прежняя оговорка сохранены.
- Источник цены сохраняется в позиции, подробном расчёте, общей спецификации и PDF; для индивидуальных настроек — отдельно по позициям.
